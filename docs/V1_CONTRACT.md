# Cortex v1.0-RC behavioral contract

A release candidate must satisfy all of the following:

1. No silent memory overflow: insufficient capacity produces explicit budget pressure / unresolved state.
2. No split from tensor suspicion alone: prospective future evidence must promote it.
3. Structural edits are reversible: split descendants may reconcile when the distinction ceases to matter.
4. Approximate/bounded memory cannot silently rewrite active structural state.
5. Known recurrence is reactivated rather than rediscovered when evidence supports an existing prototype.
6. Local change should reopen only its declared dependency closure unless a global witness fires.
7. Entity, regime, tensor, relation and compute budgets are explicit configuration values.
8. Structural actions are inspectable: maintain, adapt, reactivate, split, merge, novel, unresolved.
9. Fixed budgets imply explicit finite memory bounds for the configured runtime.
10. Resource exhaustion must reduce confidence / raise unresolved state, never fabricate certainty.
